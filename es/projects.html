Proyectos y procura

Tanques, tubería, válvulas, telemetría y suministro para refinerías que mantienen la producción y el proceso en marcha, con fábricas calificadas, proveedores autorizados por el fabricante y contratistas certificados.

Imagen ilustrativa de columnas de destilación en transporte de carga pesada; no es una operación de CRIPTOIL. Foto: Carlos Valenzuela, CC BY-SA 4.0, fuente, recortada.

Lo que suministramos

Seis líneas de producto para operaciones de upstream, midstream y refinación. Las normas se citan como referencia; la orden de compra define cada suministro.

Tanques de almacenamiento

  • Tanques soldados según API 650 y tanques de baja presión según API 620.
  • Materiales para inspección, reparación y modificación según API 653.
  • Techos flotantes, sellos, serpentines de calentamiento y accesorios de tanque.

Imagen ilustrativa, no es instalación de CRIPTOIL. Foto: Carol M. Highsmith, Biblioteca del Congreso, dominio público.

Tubería

  • Casing y tubing sin costura según API 5CT, en grados como L80 y P110, y slotted liners para control de arena en pozos de crudo pesado.
  • Tubería de línea según API 5L para oleoductos, poliductos y gasoductos.
  • Tubería de proceso según ASTM A106 y A53, bridas según ASME B16.5 y conexiones según ASME B16.9.

Foto: archivo de suministro de nuestro equipo, Houston.

Válvulas

  • Válvulas de compuerta, globo y retención según API 600, API 602 y API 594.
  • Válvulas de bola y de línea según API 608 y API 6D, con prueba de fuego API 607.
  • Cabezales de pozo y árboles según API 6A, y actuadores de válvula.

Foto: archivo de suministro de nuestro equipo, Houston.

Telemetría e instrumentación

Telemetría e instrumentación

  • Transmisores de presión, presión diferencial, temperatura y caudal.
  • Medición radar de nivel en tanques y control de inventario.
  • Sistemas RTU, PLC y SCADA, y telemetría inalámbrica para pozos, tanques y ductos.
  • Equipos certificados para áreas peligrosas (ATEX, IECEx, Clase I División 1).

Refinación

  • Equipos de proceso, repuestos y materiales para paradas de planta en refinerías.
  • Bombas centrífugas según API 610 e intercambiadores de carcasa y tubos según API 660 y TEMA.
  • Internos de columna, refractarios, empaquetaduras y tornillería.

Generación de energía

Generación de energía

  • Generación a gas con turbinas aeroderivadas e industriales y motores reciprocantes de fabricantes de primer nivel.
  • Subestaciones, celdas de maniobra y conversión de frecuencia 50/60 Hz, con contratistas calificados.
  • Operación y mantenimiento con proveedores autorizados por el fabricante.

El suministro de equipos está sujeto a revisión de controles de exportación y sanciones y requiere las autorizaciones aplicables al destino.

Calidad y trazabilidad

Cada envío lleva la documentación indicada en la orden de compra, como certificados de material EN 10204 3.1 o 3.2, informes de inspección y listas de empaque.

La inspección de tercera parte y los puntos de espera se acuerdan con el cliente antes de iniciar la fabricación.
